Lodge Complaint: Any student in the class can submit an issue.
2
Democratic Voting: Classmates vote Agree or Disagree.
3
Dynamic Threshold: When class support reaches >40% (e.g. 31+ for class of 70), status changes to Threshold Reached.

Admin Review: High-priority administrative action & decision.
